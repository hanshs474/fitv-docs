# Plans and API runs

Free image to video AI with no daily cap: start with no sign-up, keep going on a free account. Every video comes with sound and no watermark.

- **On the site:** the generator on [freeimagetovideo.ai](https://freeimagetovideo.ai/?utm_source=readthedocs&utm_medium=docs) starts with no sign-up and keeps going on a free account. See the [free unlimited AI video generator](https://freeimagetovideo.ai/video/free-unlimited-ai-video-generator).
- **From the API, an SDK or MCP:** runs need a paid plan. Each run draws on the plan's daily full-speed allowance, then waits in the relaxed queue (the status answer reports `queued` and `queueEta` while it waits).

Plans and what each includes: [freeimagetovideo.ai/pricing](https://freeimagetovideo.ai/pricing?utm_source=readthedocs&utm_medium=docs). Keys: [freeimagetovideo.ai/settings/apikeys](https://freeimagetovideo.ai/settings/apikeys).
